# 3D CAD Models & Electronic Components Library

Welcome to the electronic components library. This repository contains 3D CAD models, datasheets, and preview renders for PCB layout and enclosure design (KiCad, Altium Designer, Fusion 360, SolidWorks, etc.).

---

## Repository Structure

Each component is located in its own subfolder and typically contains:
* **3D Models:** `.step` (universal) and `.f3d` (Fusion 360 source).
* **Datasheets & Drawings:** `.pdf` or `.jpg` spec sheets.
* **Previews:** Render images (`/images` or `preview.png`) for quick inspection.
