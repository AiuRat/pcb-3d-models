### File Inventory

* `ATF-26884.step`: Lossless, high-compatibility STEP format for PCB layout (KiCad, Altium, etc.) and mechanical CADs.
* `ATF-26884.f3d`: Native Autodesk Fusion project file with parametric sketches and timeline.
* `datasheet.pdf`: Official technical datasheet (Agilent Technologies).
* `images/`: Directory containing PNG render previews and drawing.

### Component Specifications

* **Package:** 84 Plastic Package (Microstrip SMD).
* **Dimensions:** Body diameter Ø 2.15 mm, total span 5.46 ± 0.25 mm, height 1.52 ± 0.25 mm, lead width 0.51 mm, lead thickness 0.20 ± 0.05 mm.
* **Pinout:** (1) Gate (beveled lead / dot indicator), (2) Source, (3) Drain, (4) Source.
* **Frequency Range:** 2–16 GHz.
