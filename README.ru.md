# 3D CAD-библиотека электронных компонентов

Высокоточные 3D CAD-модели электронных компонентов, смоделированные строго по техническим описаниям (даташитам) производителей.

## Интеграция с ECAD и MCAD

Все модели в каталоге `components` оптимизированы для прямого импорта как в программные комплексы ECAD для проектирования печатных плат (**Altium Designer**, **KiCad**, **EasyEDA**), так и в пакеты машиностроительных САПР (MCAD) (**SolidWorks**, **Autodesk Inventor**, **КОМПАС-3D**).

## Программное обеспечение и форматы

Модели созданы с использованием **Autodesk Fusion**. Папка каждого компонента содержит:

* **STEP (`.step` / `.stp`)**: Универсальные 3D-файлы без потери точности для импорта в ECAD/MCAD.
* **F3D (`.f3d`)**: Исходные параметрические файлы проекта в собственном формате Autodesk Fusion.
* **PDF (`.pdf`)**: Официальные технические описания (даташиты) производителей для справки.
* **PNG (`.png`)**: Рендеры высокого разрешения и предварительный просмотр габаритных чертежей.
